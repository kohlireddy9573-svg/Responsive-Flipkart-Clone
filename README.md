# Responsive Flipkart Clone

A responsive, static storefront inspired by Flipkart. The page includes a shopping header, product category navigation, promotional banners, featured deals, and a multi-column footer.

## Preview

Open `scaffold.html` in a web browser. No build tools, package installation, or server are required.

## Features

- Responsive layouts for the header, category list, banners, deals, and footer
- Search field and Login and Cart controls for presentation
- Product and promotion imagery loaded from external URLs
- Plain HTML and CSS with no JavaScript dependencies

The search, Login, and Cart controls are visual only; this project does not implement shopping or account functionality.
